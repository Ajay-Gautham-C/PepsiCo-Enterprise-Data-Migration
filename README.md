# 🚀 Enterprise Data Migration & Analytics Project

## 📌 Project Overview
This project demonstrates an **end-to-end enterprise data migration and analytics solution** inspired by a real-world project at PepsiCo.  

Data was migrated from multiple heterogeneous sources such as **SAP, IRI, Excel, and flat files** into **Azure Cloud**.  
The solution involved **data ingestion, transformation, storage, modeling, and reporting** using **Azure Data Factory, Databricks, Azure Data Lake, Azure Synapse Analytics, SQL, and Power BI**.  

This architecture provided a **centralized analytics platform** for global stakeholders, enabling faster, data-driven decision-making.

---

## 🛠 Tools & Technologies
- **Data Sources:** SAP, IRI, Excel, Flat Files  
- **Data Ingestion & Pipeline Orchestration:** Azure Data Factory (ADF)  
- **Data Transformation & Processing:** Databricks (PySpark, Delta Lake)  
- **Data Storage & Modeling:** Azure Data Lake, Azure Synapse Analytics  
- **Visualization & Reporting:** Power BI  
- **Querying:** SQL  

---

## 🔑 Responsibilities
- Designed and implemented **ETL pipelines** using **Azure Data Factory**  
- Developed **data transformation scripts** in **Databricks** (PySpark)  
- Modeled **fact and dimension tables** in **Azure Synapse Analytics**  
- Wrote **SQL scripts** for data cleaning, transformation, and KPI aggregation  
- Supported **Power BI dashboard development** with optimized queries  
- Ensured **data quality, governance, and performance optimization**  

---

## 📊 Business Impact
- Consolidated data from multiple sources into a **centralized analytics platform**  
- Reduced manual reporting by **60%**  
- Improved **query performance** and efficiency of dashboards  
- Delivered **real-time insights** for Sales, Finance, and Supply Chain teams
